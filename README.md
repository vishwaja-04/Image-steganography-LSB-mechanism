Image Steganography Using LSB Mechanism

📌 Description

Image Steganography is a C-based application that hides secret text messages inside a BMP image using the Least Significant Bit (LSB) technique. It embeds secret data into the pixel data of an image by modifying the least significant bits, making the changes difficult to notice visually.

The application supports encoding a secret text file into a BMP image and decoding the hidden message from the encoded image.

✨ Features

- Encode secret text data into a BMP image.
- Decode hidden messages from an encoded image.
- Use a text file as the secret message source.
- Support BMP images as the cover image.
- Preserve the visual appearance of the image by modifying the least significant bits.
- Provide a command-line interface for encoding and decoding operations.

 Technologies Used
 
- Language: C
- Mechanism: Least Significant Bit (LSB) Steganography
- Concepts: Bitwise Operations, File Handling, Pointers, Structures, and Command-Line Arguments.
- Compiler: GCC
